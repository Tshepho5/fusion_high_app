# Import learners from SA-SAMS into Geleza SA

## At the school (SA-SAMS PC)

1. Open SA-SAMS with data-capturer / admin access.
2. Go to **Menu 16.3 → Export Data Fields to MS Excel**.
3. Select main table **Learner Info** (optionally also Parent Info later).
4. Filter grade / status / year if needed.
5. Export → open in Excel → **Save As → CSV (Comma delimited) (*.csv)**.
6. Send the CSV to the Geleza school admin (or upload yourself).

## In Geleza SA

1. Sign in as principal / school admin.
2. Open **More → Import Learners (SA-SAMS CSV)**  
   or **Users → Import SA-SAMS CSV**.
3. Upload the CSV.
4. Confirm column mapping (auto-detected for common SA-SAMS headers).
5. Preview valid rows → **Import**.
6. Share the default password with learners (or force reset on first login later).

## Limits & notes

- Max **500** learners per batch.
- Duplicates (learner number / ID / email) are skipped by default.
- Parent contacts are often incomplete in SA-SAMS — parents still apply / register in Geleza.
- POPIA: only import after the school has agreed to process data in Geleza.
